- Imported triangles: 225,154
- Dimensions: approximately 60.001 × 31.004 × 48.000 mm

The importer excludes 552 collapsed triangles whose indices repeat a vertex
after STL vertex welding. This does not move vertices or change the nonzero-area
surface. The imported mesh is a closed, consistently oriented positive volume.
The bundled original file retains the collapsed triangles for reproducible tests.
